# 素材来源

## 官方封面

- `public/img/box-gwt-new-zealand.jpg`：《大西部开拓者：新西兰开拓史》简体中文版（本长文化）官方平面封面，BGG 图 7713645 原图（999×999 JPEG），逐字节下载，没有放大、裁剪或重绘。给总入口转盘用。
- `public/img/cover.jpg`：同一张图缩到 400×400，本站首页和结算长图用。

## 讲规则页图片

`public/img/teach/*.webp`，41 张，共约 300 KB。截自 eggertspiele 官方英文规则书（2023-03，20 页，BGG 文件页 262566，即 `EN-GWT_NZ_Rulebook_final_low_res.pdf`），版权 © 2023 eggertspiele / Plan B Games Europe GmbH，页脚署名并链接原文。

做法：`pdftoppm -r 300` 渲染单页，按坐标裁剪，压成 webp（图标最长边 140–240 px，版图类 480–760 px），每页裁完立刻删掉渲染图，只留成品。裁完拼成总览图逐张核对，截进文字的（帆船、圆片）重裁或抹掉。PDF 本身是低分辨率版，所以放大的版图图不太清楚。

## 原创插画

由 Codex CLI（`codex exec`，内置 image_gen）生成，2026-11-13。

提示词要点：19 世纪新西兰牧羊题材，水粉加纸纹，色调为深海青、牧草绿、羊毛米白、赭黄；不要文字、标志、游戏配件，不模仿任何桌游封面。
